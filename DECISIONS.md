## 2026-09-04 — v0.2.1 session decisions (UTC 2026-09-04T16:16:35Z)
1. **SQLite engine uses NullPool**: route handlers open sessions directly (no FastAPI Depends teardown); QueuePool + GC-delayed returns deadlocked the API after ~15 requests. NullPool = no cap; SQLite connections close with session GC.
2. **Next 14 params are plain objects**: all dynamic pages converted from `params: Promise<...>` + `use()` (Next 15 style, crashes on 14) to direct props. This was the root cause of "pages not opening".
3. **Motion hiding gated on `html.js`**: `.reveal` only hides when JS is present (inline head script adds the class); content fully visible without JS and under reduced motion.
4. **Dataset-card image chain**: publisher og:image (robots-aware, rate-limited, SSRF-guarded) → local domain artwork → deterministic SVG initials. INQETRA never mirrors or hosts third-party images.
5. **Basket report saves browser basket into the project before evaluating** (same rule as drawer save-to-project): coverage matrix always reflects real project-basket rows; nothing is auto-published.
6. **Generated art library** (Mohamed-delivered, 53 assets) wired: hero, kit covers, domain placeholders, banners, empty states, sticker sheet, favicon/OG. Logo v3 replaces v2 (v2 archived at `assets/logo_previous_2026-09-04.png`).
7. **Web dev/verify port 3100** in this environment (3000 held by colima ssh mux); compose still maps web 3000.
