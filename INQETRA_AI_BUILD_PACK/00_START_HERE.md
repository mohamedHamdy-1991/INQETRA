# 00 — Start Here

## Product identity
- **Name:** INQETRA
- **Category:** Research design studio + UK dataset hub + evidence architecture tool
- **Primary audience:** PhD/MSc researchers, academics, consultants, planners, GIS analysts, built-environment researchers, students and public-sector analysts.
- **Initial geographic emphasis:** United Kingdom, with England/Scotland/Wales/Northern Ireland explicit in metadata.
- **Initial domain emphasis:** built environment and adjacent socioeconomic/environmental systems.

## North-star outcome
A researcher begins with an incomplete research idea and leaves with:
1. structured research questions;
2. aligned aims/objectives;
3. methodology and methods;
4. explicit dataset requirements;
5. a selected dataset basket;
6. compatibility and data-gap analysis;
7. a reproducible acquisition/analysis plan;
8. linked notes and evidence;
9. an evidence-traceable abstract draft;
10. an exportable Research Data Plan.

## Non-negotiable model
`Research Problem → Gap → RQs → Aims → Objectives → Hypotheses → Methodology → Methods → Dataset Requirements → Candidate Datasets → Basket → Aim×Dataset Assignment → Transformations/Joins → Analysis → Results entered by researcher → Contribution → Abstract`

These are linked first-class objects, not one long rich-text field.

## Build order
Audit → schemas → taxonomy → database → catalogue → global search → dataset detail → project graph → RQ/Aim/Method matrices → basket → compatibility → gap radar → notes → research kits → abstract builder → crawler → AI tools → reports → admin → QA.
