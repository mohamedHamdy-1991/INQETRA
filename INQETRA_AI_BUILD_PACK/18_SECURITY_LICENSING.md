# Security, Privacy & Licensing

Anonymous catalogue browsing. Account required for synced projects/submissions. Minimal personal data. Private project metadata remains private unless explicitly shared.

Security baseline: CSRF/XSS/SQLi protections; strict server validation; sanitise harvested HTML; SSRF protections for user URLs/link checker; crawler egress allowlist; rate limits; secret manager; dependency scanning; backups and restore tests; audit trail; role-based admin access.

Licensing model: index metadata and official links by default. Do not infer open reuse from public availability. Store source-declared licence, normalised family, verification state and exact source text/link. High-priority warning for unknown/restrictive licence.

Digimap and premium OS entries are entitlement-aware catalogue records; never bypass authentication and never redistribute licensed content by default.
