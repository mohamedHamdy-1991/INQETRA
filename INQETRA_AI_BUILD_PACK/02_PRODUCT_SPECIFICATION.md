# INQETRA Product Specification

## Product statement
INQETRA is a research-navigation platform that links the logic of a thesis to the data required to execute it. It is not simply a dataset catalogue and not a black-box thesis writer.

## Jobs to be done
- Turn a vague research problem into structured questions and aims.
- Verify that every aim has a method and evidence requirement.
- Discover authoritative data for each requirement.
- Understand geography/time/variable/licence/access compatibility before download.
- Record why each dataset belongs in the project.
- Keep notes, decisions and dataset provenance in one workspace.
- Export a supervisor-ready/project-ready research plan.
- Draft an abstract only from project facts entered or linked by the researcher.

## Trust model
Facts displayed about a dataset must map to publisher metadata, harvested source evidence, curator enrichment or explicitly marked user/AI enrichment. Metadata completeness is not scientific quality. Search relevance is not dataset quality.

## Primary outputs
Dataset catalogue; Dataset Detail; Project Basket; Research Design Studio; relationship matrices; Compatibility Report; Coverage Matrix; Data Gap Radar; Acquisition Plan; Analysis Plan; Research Notebook; Abstract Draft; Research Data Plan; citations; machine-readable manifest.

## North-star metric
Projects that reach a complete exported research/data plan, not raw indexed-record count.
