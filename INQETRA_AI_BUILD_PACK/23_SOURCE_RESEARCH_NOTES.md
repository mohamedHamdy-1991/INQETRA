# Source Research Notes — 4 September 2026

These notes document the public sources used to shape the initial seed and adapters. They are not a replacement for runtime revalidation.

- National Data Library CKAN API documentation: https://guidance.data.gov.uk/get_data/api_documentation/
- Planning Data dataset catalogue: https://www.planning.data.gov.uk/dataset/
- Planning Data API documentation: https://www.planning.data.gov.uk/docs
- ONS Open Geography Portal: https://geoportal.statistics.gov.uk/
- Ordnance Survey OpenData: https://www.ordnancesurvey.co.uk/products/open-data
- Ordnance Survey product catalogue: https://www.ordnancesurvey.co.uk/products/search-for-os-products
- Digimap products/help: https://digimap.edina.ac.uk/help/our-maps-and-data/
- Met Office HadUK-Grid datasets: https://www.metoffice.gov.uk/research/climate/maps-and-data/data/haduk-grid/datasets
- Defra Data Services Platform: https://environment.data.gov.uk/
- Historic England open listing data: https://historicengland.org.uk/listing/the-list/data-downloads/
- EPC England/Wales data service: https://get-energy-performance-data.communities.gov.uk/
- DESNZ electricity: https://www.gov.uk/government/collections/sub-national-electricity-consumption-data
- DESNZ gas: https://www.gov.uk/government/collections/sub-national-gas-consumption-data
- HM Land Registry Price Paid Data: https://www.gov.uk/government/statistical-data-sets/price-paid-data-downloads
- DfT Road Traffic API docs: https://roadtraffic.dft.gov.uk/api-documentation
- Police open data: https://data.police.uk/
- Fingertips Wider Determinants: https://fingertips.phe.org.uk/profile/wider-determinants/data
- NISRA geography/data: https://www.nisra.gov.uk/support/geography
- Public Health Scotland Open Data: https://www.opendata.nhs.scot/
- DataMapWales: https://datamap.gov.wales/

Crawler implementation should add Scotland, Wales, NI, local-authority ArcGIS/CKAN portals, UK Data Service/Census, BGS, CEDA/MIDAS, UKCP, Copernicus, VOA, Ofcom, NaPTAN/BODS and other sources as validated adapters rather than uncontrolled web scraping.
