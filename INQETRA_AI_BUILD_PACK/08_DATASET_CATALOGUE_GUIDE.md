# Dataset Catalogue Seed Guide

The seed contains **751 records** across planning, ONS geography, HadUK-Grid partitions, Ordnance Survey, heritage, flood/terrain, energy, housing, property, transport, health, crime, Northern Ireland and Digimap collection metadata. The 2026-09-04 upgrade adds a curated UK climate, air-quality, flood-projection, building-condition, housing-energy, and local carbon-emissions tranche.

## Files
- `data/datasets_seed.csv` — easiest database seed input.
- `data/datasets_seed.json` — typed ingestion / frontend fixture.
- `data/DATASET_CATALOGUE.md` — human-readable index.
- `data/link_health/catalogue_link_health.csv` — record-level HTTP landing-page health result, regenerated by `scripts/validate_catalogue_links.py`.

## Link semantics
- `direct_dataset`: dataset-level official page/API.
- `official_collection`: official page containing the named product/partition.
- `official_search_query`: authoritative portal search for the exact named dataset family; resolver must locate current item.
- `api_endpoint` / `api_documentation`: live structured service or its contract.
- `official_product_catalogue`: named product confirmed in official catalogue, direct product URL still to resolve.

## Verification semantics
Never publish all seeds as "verified". `partition_of_verified_dataset` means the parent product explicitly documents the partition convention. `indexed_family_from_official_portal` means the official portal taxonomy supports the family, but the ingestion worker must resolve the specific item ID and snapshot its metadata.

`official_landing_page_link_checked` means that the official landing page returned HTTP 200–399 at the recorded check time only. It does **not** confirm resource-level access, scientific fitness, metadata fields, licence terms or redistribution rights. `collection_record_link_checked` is the equivalent state for a working official collection page where a legacy or ambiguous direct record still needs resolver/curator confirmation.
