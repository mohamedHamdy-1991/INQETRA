# Implementation Roadmap

## Phase 0 — Audit & foundation
Inventory existing repo; preserve routes/hooks; establish design tokens; canonical schemas; migrations; seed importer; test fixtures.

## Phase 1 — Dataset hub
Catalogue, facets, detail, source provenance, variable browser, basket, compare, publishers/sources.

## Phase 2 — Research graph
Projects, questions, aims/objectives, methods, requirements, matrices, research readiness dimensions.

## Phase 3 — Compatibility & gaps
Rule engine, coverage matrices, Data Gap Radar, candidate inbox.

## Phase 4 — Notebook, kits, report
Notes, Research Kits, acquisition/analysis plan, PDF/HTML/Markdown/CSV/JSON/BibTeX/RIS exports.

## Phase 5 — Crawler
Source Registry, CKAN/Planning Data/ArcGIS/OGC adapters, resolver, link health, admin queues.

## Phase 6 — Optional AI
Tool-driven copilot, external discovery orchestration, evidence-traced methods/abstract drafting.

## Phase 7 — scale/trust
Saved searches/watches, publisher corrections, collaboration, broader UK sources, search scaling.
